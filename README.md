# huashu × HyperFrames 원본 이미지 가이드

사용자가 제공한 HTML 문서와 원본 이미지 8종을 포함한 정적 사이트입니다.

## GitHub Pages 배포

Settings → Pages → Deploy from a branch → main / (root) → Save.
별도 빌드나 서버, API 키가 필요 없습니다.

## 기능

- 한국어 문서 및 9개 애니메이션 문법 안내
- 원본 예제 이미지 8종 확대, 이동, 이전/다음 보기
- 이미지가 포함된 오프라인 ZIP 저장

## 출처

원본: https://github.com/alchaincyf/huashu-art-motion
원본 커밋: `64cb27271ee0ad3375298e2890b33cbec36d4051`.
각 이미지 크기와 Git blob SHA-1은 `asset_manifest.json`에 기록되어 있습니다. 이미지 바이트는 수정하지 않았습니다. Y6는 원본 이미지가 없어 설명만 제공합니다.

이미지와 캐릭터의 권리는 원저작자에게 있습니다. 원본 저장소 README의 라이선스 예외와 각 자산의 이용 조건을 따릅니다.
